Unidad 2

Sitio Web

Concepto

Esta unidad se enfoca en la construcción y diseño de un sitio web con una estructura organizada, una navegación clara y contenido pensado para la presentación de ideas y proyectos. Se aplican conceptos de usabilidad, visualización y experiencia del usuario.

  • Diseño responsivo para distintos tamaños de pantalla.
  • Uso de HTML y CSS para una interfaz legible.
  • Presentación visual alineada con un enfoque tecnológico.
